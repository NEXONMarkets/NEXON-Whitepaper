# Roadmap

The roadmap uses verifiable delivery gates rather than implied return milestones.

| Gate | Verifiable completion evidence |
|---|---|
| Economic authority | Versioned rules reproduce the approved 72/28, vesting, staking and redemption calculations |
| Layer separation | NEX spot and Staking Platform permissions, ledgers and disclosures are independently testable |
| Order accounting | Every order records principal, build, staking base, term, weight and parameter version |
| Redemption | T+0, 30D and 60D paths reconcile net release and equivalent EXON burn |
| Risk controls | Reviews, audits, monitoring, incident handling and public change notices are operational |
| Open fields | Supply, allocation, dynamic levels and round terms are published only after formal approval |

Dates, contract addresses, service availability and jurisdiction coverage should be announced through official channels when confirmed. A guide price, APY or worked example is not a roadmap target.
