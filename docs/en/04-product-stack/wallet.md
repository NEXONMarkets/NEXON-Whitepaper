# Wallet — State and Control

The Wallet is the user's view of account state and permissions. It should distinguish spot balances from Staking Platform positions and show the responsible system for every action.

For tokenomics, the Wallet should display principal `P`, the 28% EXON build, the 72% XO staking base, term and weight, epoch accruals, vesting release, fuel-reserve status and the selected redemption lane. It should also show the parameter version used to calculate each amount.

The Wallet does not create a separate yield source. All NEXON staking rewards described in this paper belong to the Staking Platform and its disclosed rules. A balance display is not proof of liquidity, executable price or recoverability.
