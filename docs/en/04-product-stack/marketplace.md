# Marketplace — the Real Leg

The Marketplace connects an approved user request to a supplier, inventory record, price and fulfilment receipt. A supplier remains responsible for the product, delivery, refund and applicable consumer terms.

The approved tokenomics does not define EXON as a universal marketplace payment asset. Any supported payment method, conversion, fee or refund must therefore be disclosed by the responsible service rather than inferred from EXON's Core Value Token role.

A completed transaction requires evidence from the supplier system. If delivery fails, the applicable service terms—not a token burn—govern refund or dispute handling.
