# Compliance & Legal Posture

NEXON is an independent, community-initiated project built within the NEX ecosystem; it is not an official NEX product. XO and EXON are NEXON project assets, not NEX platform tokens.

The operating boundary is explicit: NEX Main Exchange/CEX is the compliant spot layer for EXON spot activity, IEO and release display. The Staking Platform separately runs single-token staking, term weighting, dynamic rewards and redemption. Exchange licences or disclosures must not be used to imply regulatory approval of a staking return.

Economic communications must distinguish four classes of statement:

| Class | Required treatment |
|---|---|
| Approved parameter | State the value, effective version and adjustability |
| Conditional illustration | State every price and execution assumption next to the result |
| Market outcome | Never guarantee price, liquidity, return or payback |
| Unpublished field | Mark open; do not estimate or complete it |

KYC, AML, custody, exchange execution and any regulated real-world activity must be performed under the applicable terms of the responsible licensed party. Availability depends on jurisdiction and participant eligibility.
