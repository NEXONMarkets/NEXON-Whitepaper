# Two Assets, Two Jobs

The approved model separates the asset used as staking principal from the asset exposed to the spot market.

| | XO | EXON |
|---|---|---|
| Canonical role | Staking Principal Token | Core Value Token |
| Acquisition | Subscription from Treasury, priced in U | Early rounds, 72/28 auto-build, spot purchase |
| Market | Internal circulation; price managed by protocol | Spot-traded on NEX from TGE |
| Economic function | Carries the staking principal and reward base | Receives programmatic buy, lock and redemption-burn demand |

`U` is the accounting unit pegged to USDT in the project paper. XO's protocol-managed price and internal circulation are deliberately separated from EXON's public secondary-market price.

The roles must not be reversed. XO is not described as a governance seat, execution ceiling or route collateral. EXON is not an execution-fee token whose consumption merely transfers it to operators. Under the current model, rapid reward redemption permanently destroys an equivalent amount of EXON.

{% hint style="info" %}
EXON is a NEXON project asset, not the platform token of NEX. NEXON is an independent, community-initiated project built within the NEX ecosystem.
{% endhint %}
