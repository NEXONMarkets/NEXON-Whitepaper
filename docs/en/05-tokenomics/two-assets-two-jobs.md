# Two Assets, Two Jobs

NEXON uses two assets because **value accumulation and active circulation are not the same job**.

**XO is the Value Anchor. EXON is the Circulation Engine.** Underneath that narrative, the approved mechanism gives each asset a narrower current function that can be implemented and audited.

## The complete role map

| Dimension | XO | EXON |
|---|---|---|
| Where the name comes from | `X`: cross-domain connection and possibility; `O`: the ecosystem loop and value accumulation | `EX`: exchange / experience; `ON`: circulation enabled |
| Narrative role | Value Anchor | Circulation Engine |
| Narrative function | Staking, participation, ecosystem rights, long-term value accumulation | Trading, payment, exchange, fees, consumption circulation |
| Current canonical label | Staking Principal Token | Core Value Token |
| Current acquisition | Treasury subscription at a protocol-managed U price | Early rounds, the 28% order build, or spot purchase |
| Current market | Internal circulation, protocol-priced | Public NEX spot activity from TGE |
| Current mechanical job | Carries the 72% staking and reward / PV base | Absorbs programmatic buying, balance checks, linear release and redemption burns |
| Long-term boundary | Governance and broader rights await published design | Payment, fee and consumption utility await product-specific support and terms |

`U` is the accounting unit pegged to USDT in the approved paper. XO's protocol-managed price and internal circulation are **deliberately separate** from EXON's public secondary-market price.

## Why the split is not optional

Treat staking principal and circulating asset as one job, and two things blur immediately: a **market price move** gets read as a change in the **interest base**, and a **product fee** gets read as the **staking fuel check**.

The dual structure keeps four questions independent:

{% stepper %}
{% step %}
### What amount establishes the reward base?

`S = 0.72 × P`, carried by XO.
{% endstep %}

{% step %}
### Which asset is exposed to public price and liquidity?

EXON, trading on the spot market from TGE.
{% endstep %}

{% step %}
### What must be in the account to qualify for an order?

EXON worth `F = 0.28 × P` — **checked, and still the user's**.
{% endstep %}

{% step %}
### What is destroyed when faster redemption is chosen?

An equivalent amount of EXON is permanently burned — 30% on the T+0 lane, 15% on 30D.
{% endstep %}
{% endstepper %}

Four questions, four different answers. No description should collapse any two of them.

## Narrative is not arithmetic

Calling XO the Value Anchor keeps it from being read as a disposable accounting entry — it ties staking participation to the long-term ecosystem thesis. It does not change its confirmed current function: **protocol-priced staking principal.**

Calling EXON the Circulation Engine explains why this asset can connect digital and real-world activity over time. It does not make it a universal payment or fee token today. Its confirmed operations right now are spot activity, release, the 28% Treasury purchase, the user balance check and equivalent redemption burns.
