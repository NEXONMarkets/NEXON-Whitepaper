# Governance

Governance must not be inferred from token ownership. The approved economic paper assigns XO the role of staking-principal token and EXON the role of core value and spot token; it does not grant either token voting rights or publish an on-chain voting design.

At the current stage, the NEXON team administers configurable parameters, including staking settings, reward payout ranges and round-specific terms. Every production change should carry:

1. an effective time and parameter version;
2. the fields changed and the orders affected;
3. a public notice through an official project channel;
4. an auditable record that prevents retroactive changes to closed epochs.

The team may not present unpublished fields as decided. Numerical EXON supply, complete allocation, initial float, future-round limits and the full Differential Matching Bonus table remain open.

NEXON is an independent, community-initiated project built within the NEX ecosystem. NEX exchange status, licences or personnel do not approve or guarantee Staking Platform outcomes.
