# Glossary

| Term | Chinese | Current definition |
|---|---|---|
| U | U | Accounting unit pegged to USDT in the approved paper |
| NEX Main Exchange/CEX | NEX 主交易所 / 合规现货层 | EXON spot trading, IEO and release display; excludes the staking reward model |
| Staking Platform | 质押与奖励层 | Single-token staking, term weighting, dynamic rewards and redemption |
| XO | 质押本金代币 | Protocol-priced internal asset carrying staking principal |
| EXON | 核心价值代币 | NEXON's sole core value and spot asset |
| 72/28 | 7228 | 28% EXON build and 72% staking-principal split |
| Fuel reserve | 燃料储备 | EXON balance equal to 28% of order value, checked before order opening and retained in the user's account |
| Epoch | 结算周期 | 12-hour reward and release interval |
| Base APY | 基础年化参数 | Approved 200% parameter before term weighting; adjustable and not guaranteed |
| Term weight | 期限权重 | Multiplier 1.00/1.10/1.20/1.35/1.50 for 30/90/180/360/540 days |
| Differential Matching Bonus | 等级极差奖励 | Adjacent-level dynamic reward method; detailed levels remain unpublished |
| Burn | 永久销毁 | Equivalent EXON removed from supply under the selected reward-redemption option |
| Treasury Liquidity | 国库底仓 | Destination for EXON acquired by the 28% build |
| TGE | 代币生成事件 | Start of EXON spot activity and 1,095-day linear release in the model |

The terms “guide price”, “APY”, “ROI” and “static payback” describe parameters or conditional arithmetic. None states a guaranteed outcome.
