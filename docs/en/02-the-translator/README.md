# The Translator

NEXON treats a user's goal as an Intent rather than forcing the user to manually operate every product. An agent proposes a route across available markets and services; the user retains approval and the responsible venue or supplier executes each regulated or real-world leg.

The five control steps are:

1. **Parse** the requested outcome and constraints.
2. **Route** through eligible venues, liquidity and suppliers.
3. **Policy Check** account eligibility, order limits, balances and required EXON fuel reserve.
4. **Execute** only the approved legs within scoped permissions.
5. **Land the Real Leg** and record completion or rollback.

The Staking Platform is not a prerequisite for agent execution. Its XO principal, EXON reserve and reward rules are a separate economic product described in [Token Economics](../05-tokenomics/README.md).
