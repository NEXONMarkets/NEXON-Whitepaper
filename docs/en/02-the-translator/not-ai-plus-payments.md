# Not “AI Plus Payments”

Spend limits, allowlists, revocation and scoped authority answer a safety question: what may an agent do? Translation answers a capability question: how can one requested outcome be resolved across systems that describe value differently?

NEXON keeps those questions separate. The agent layer interprets Intent and proposes controlled execution. The economic layer separately defines a 72/28 order split, XO staking principal, EXON spot-market value, term-weighted rewards and redemption burns. No token balance substitutes for user approval or regulated execution.

This separation matters for disclosure. Product automation does not make a staking parameter safer; a high APY does not prove product adoption; an exchange listing does not validate an agent's output. Each statement must be supported on its own terms.
