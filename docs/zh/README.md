# NEXON 白皮书

NEXON 是基于 NEX 生态、由社区发起的独立项目，不是 NEX 官方产品；EXON 也不是 NEX 平台币。

产品命题是用 Agent 协助连接资本市场、数字资产与真实使用。经济架构在统一账户下设置两个独立运营层：NEX Main Exchange/CEX 承载 EXON 现货、IEO 与释放呈现；Staking Platform 承载单币质押、期限权重、动态奖励与赎回。
