## NEXON 是什么 <a href="#what-nexon-is" id="what-nexon-is"></a>

NEXON 是新一代价值连接网络：让 AI Agent 在资本市场、数字资产与真实消费之间做实时翻译，把你想要的，变成已经结算的。

世界的价值分布在三个市场里，而它们互相读不懂对方。股票说的是所有权和未来的现金流，它 T+2 结算，止步于国境。数字资产说的是流动性，它秒级结算，止步于现实世界的边缘。旅游、酒店、零售说的是使用权——在某个时间、某个地点，能用。同样的价值，三种从一开始就没打算互通的语言。

把一笔仓位变成一间酒店房间，今天仍然要经过四个系统、四次身份验证、大约一周时间。每一步，都是一个人在手动把一种价值语言翻译成另一种。在软件只会搬运价值的年代，这还可以忍受。从软件能读懂价值的那一刻起，它就不再可以忍受了。

NEXON 把 Agent 放进这道缝隙里。你说出一个 Intent（意图），Agent 解析它、在三个市场之间规划路径、从头到尾结算——一直落到 Real Leg（现实腿）。这个连接不是靠桥，是靠 Agent。

NEXON 是在 NEX 生态内由社区自发发起的独立项目，不是 NEX 的官方产品；XO 与 EXON 都不是交易所平台币。

| 徽章 | 含义 |
| --- | --- |
| `Live` | 已部署，今天可用。 |
