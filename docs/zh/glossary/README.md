## 用词纪律 <a href="#usage-discipline" id="usage-discipline"></a>

「指导价」「年化」「ROI」「静态回本」描述的是**参数或条件化算术**，其中没有一项陈述一个有保证的结果。「价值锚」不表示稳定的价格或法律上的索取权。「流通引擎」不表示 EXON 已被每一种支付或费用场景接受。

叙事术语与机制术语同时出现时，**两层都要说**。推荐写法：

> XO 是价值锚，当前是质押本金代币；更广的权益需要单独发布的规则。
>
> EXON 是流通引擎，当前是核心价值代币与现货 / 释放 / 买入 / 校验 / 销毁资产；更广的应用用途需要产品条款。
