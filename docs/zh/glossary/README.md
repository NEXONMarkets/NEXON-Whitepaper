# 术语表

| 英文 | 中文 | 现行定义 |
|---|---|---|
| U | U | 定稿中与 USDT 锚定的计价单位 |
| NEX Main Exchange/CEX | NEX 主交易所 / 合规现货层 | EXON 现货、IEO 与释放呈现；不运行质押奖励模型 |
| Staking Platform | 质押与奖励层 | 单币质押、期限权重、动态奖励与赎回 |
| XO | 质押本金代币 | 由协议定价、在体系内承载质押本金的资产 |
| EXON | 核心价值代币 | NEXON 唯一核心价值代币与现货资产 |
| 72/28 | 7228 | 28% EXON 建仓与 72% 质押本金拆分 |
| Fuel reserve | 燃料储备 | 开单前校验、仍留在用户账户的订单额 28% 等值 EXON 余额 |
| Epoch | 结算周期 | 12 小时奖励与释放周期 |
| Base APY | 基础年化参数 | 期限加权前的 200% 已定参数；可调且不受保证 |
| Term weight | 期限权重 | 30/90/180/360/540 天对应 1.00/1.10/1.20/1.35/1.50 |
| Differential Matching Bonus | 等级极差奖励 | 相邻等级动态奖励方法；详细等级尚未公布 |
| Burn | 永久销毁 | 按收益赎回选项从供给中移除的等值 EXON |
| Treasury Liquidity | 国库底仓 | 28% 建仓所得 EXON 的去向 |
| TGE | 代币生成事件 | 模型中 EXON 现货与 1,095 天线性释放的起点 |

“指导价”“APY”“ROI”“静态回本”只描述参数或条件化数学，不代表保证结果。
