# 断裂

> 同样的价值，三种从一开始就没打算互通的语言。

券商账户里的一笔仓位、钱包里的一枚代币、酒店里的四个晚上，都是价值。这一点没有人会争。不容易看见的是另一件事：它们从来没有在同一本账上出现过。每一个都活在自己的系统里，各有各的时钟、各有各的计价单位、各有各的边界；而这三套系统在建造之初，从没打算要碰面。

通常的说法是：资本市场、数字资产与真实消费长期彼此独立。这话不错，但它什么也没解释。独立是结果，不是原因。如果原因只是「没人修桥」，问题早就该解决了，因为管道从来不缺。链与链之间架了桥，链上余额能刷卡花掉，现实资产也被登记成了代币。三个市场照旧各在各处。

## 原因是缺一种语言 <a href="#the-cause-is-a-missing-language" id="the-cause-is-a-missing-language"></a>

看一看每个市场说的「价值」各指什么，这种分离就不再神秘。

在资本市场，价值是所有权，是对未来现金流的一份权利。它按季度的节拍走，结算有延迟，到了司法辖区的边缘就停下。在数字资产里，价值是流动性与可组合性。它每天每小时都在动，几秒内结算，不认任何国界——却几乎没有办法作用于自身之外的任何东西。在真实消费里，价值是使用某样东西的权利：某个晚上的一间房，某个傍晚的一张桌，一件送到手上的货。它以时间、地点和可用性来计量，到供应商的库存边缘为止。

三种价值的定义，三种时钟，三种边界。没有一种是错的，也没有一种能被另外两种读懂。市场之所以断裂，原因就在这里：不是没人把它们连起来，而是它们之间没有一种可以用来表达「连接」的共同语言。在其中两个市场之间架一根管道，价值过去了，含义留在原地；总得有人——而且永远是一个人——在管道的另一头把含义重新补上。

## 为什么是现在 <a href="#why-this-matters-now" id="why-this-matters-now"></a>

只要软件还只会搬运价值，这种安排就还能忍受。搬运本身就是难点，两头的翻译是一笔人人都在付、却没人给它起名的成本。现在，软件能读懂一个请求的含义了。从它能读懂的那一刻起，这笔成本就不再隐形；断裂也就不再是一种生活常态，而变成了一个有形状的问题。

第一部分描述的就是这个形状。它不提出任何方案。它解释这份文件所用的名字，摆出三种语言，跟着一个再普通不过的请求走完全部三个市场，再逐一检查已有的解法各自真正解决了什么。方案从第二部分开始。
