# PayFi —— Agent 的手

PayFi 是执行已批准支付或兑换指令的受控入口，适用账户资格、报价有效期、场所限制、限定权限、回执与回滚处理。

如有产品费用，应按对应服务条款披露。定稿经济模型未把 EXON 定义为通用 PayFi 手续费或结算代币；持有 XO 也不授予执行限额。质押收益与赎回销毁只存在于独立 Staking Platform。

这条边界防止产品功能静默改变代币需求假设，也防止质押余额变成支付权限。
