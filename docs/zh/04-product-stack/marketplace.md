# 商城 —— 现实落地

商城把已批准的用户请求连接到供应商、库存、价格与履约回执。供应商仍对商品、交付、退款与适用消费者条款负责。

定稿经济模型没有把 EXON 定义为通用商城支付资产。任何支持的支付方式、兑换、费用或退款，都必须由责任服务方披露，不得从 EXON 的核心价值代币角色推导。

交易完成需要供应商系统的证据。交付失败时，退款或争议由适用服务条款处理，而不是由代币销毁机制处理。
