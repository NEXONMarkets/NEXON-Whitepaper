# 意图层

Intent 捕获一个目标，同时不隐藏实现它所需的操作。最小 schema 记录所有者、期望结果、金额、截止时间、场所限制、价格容忍度与审批模式；缺少重要字段时，在提出路径前追问。

经济订单增加产品类型与参数版本。质押订单记录本金 `P`、建仓 `B`、质押基数 `S`、期限、权重、燃料校验及随后选择的赎回进度。不可变关系是：

```text
B = 0.28 × P
S = 0.72 × P
```

schema 不得把 EXON 改成无关路径的执行成本单位；非质押产品费用应遵循各自披露条款。
