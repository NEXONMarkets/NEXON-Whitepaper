# Agent 运行时

运行时绑定单一账户，应持有限定权限而不是无限密钥。它提出路径、等待所需审批、逐段授予权限，并在下一步前检查撤销状态。

三层嵌套控制：

1. 账户与辖区资格；
2. 用户批准、可见的路径金额和截止时间；
3. 每段的资产、场所、金额与有效期限制。

对于 Staking Platform 订单，运行时额外校验 `F = 0.28 × O` 的 EXON。它只是余额检查，EXON 仍在用户账户。XO 承载质押本金，但不决定 Agent 的执行上限或治理权。

每个事件都应记录责任方、规则版本、输入余额、决定与结果回执。除非已批准条款明确规定，具体产品限额与代币持有量相互独立。
