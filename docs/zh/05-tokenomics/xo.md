# XO —— 质押本金代币

XO 是定稿经济模型中的质押生息本金载体。用户向 Treasury 申购，以 U 计价并由协议统一管理价格。它在体系内流转，独立于公开二级市场。

一笔完整 U 订单中，72% 成为质押本金：

```text
S = 0.72 × P
```

`S` 是静态质押收益和动态奖励使用的 PV/计息基数。28% EXON 建仓是独立部分，不增加这一基数。

XO 的职责有意保持单一。它既不是 NEX 平台币，也不是 EXON 的替代品。定稿没有给出 XO 数字总量或公开上市计划。

{% hint style="warning" %}
“本金载体”不代表本金受保障。30 天档提前退出会扣除 `S` 的 10%–15%；所有参与仍面临协议、市场、流动性、托管与法律风险。
{% endhint %}
