# 双币，两份工作

NEXON 用两种资产，是因为**价值沉淀和活跃流通不是同一份工作**。

**XO 是价值锚。EXON 是流通引擎。** 在这条叙事之下，现行机制又给每种资产一份更窄、可实现、可审计的当前功能。

## 完整角色表 <a href="#the-complete-role-map" id="the-complete-role-map"></a>

| 维度 | XO | EXON |
|---|---|---|
| 名字怎么来的 | `X` 跨域连接与可能性；`O` 生态闭环与价值沉淀 | `EX` exchange / experience；`ON` 流通开启 |
| 叙事角色 | 价值锚 | 流通引擎 |
| 叙事功能 | 质押、参与、治理与长期价值沉淀 | 交易、支付、兑换、费用与消费流通 |
| 当前正式名称 | 质押本金代币 | 核心价值代币 |
| 当前获取方式 | NEX 二级市场自由交易；质押入金即兑换 | 私募认购 0.1 U，唯一渠道 |
| 当前市场 | NEX 自由买卖 | 上线 1.0 U；NEX 只挂卖单、不挂买单，卖出手续费 2% |
| 当前机制作用 | 承载质押本金；静态收益、推广奖励、领导奖金一律以 XO 发放 | 入金的 28% 买入存入燃料钱包；提取收益时销毁，永久退出流通 |
| 总量 | 10 亿枚 | 10 亿枚，私募只放 2 亿枚 |

`U` 是计价单位，锚定 USDT。XO 的市场与 EXON 的市场是**刻意分开**的两件事：一个自由买卖，一个只能卖不能买。

## 为什么非分开不可 <a href="#why-the-split-is-not-optional" id="why-the-split-is-not-optional"></a>

如果把质押本金和流通资产当成同一份工作，两件事会立刻糊掉：一次**市场价格波动**会被误读成**计息基数变化**；一次**燃料销毁**会被误读成**本金损耗**。

双币结构把四个问题保持独立：

{% stepper %}
{% step %}
### 什么在计息？

质押入金兑换成的 XO。每 12 小时结算一次，单次 0.3% – 1.0%，质押 1,000 U 一天 6 – 20 U。
{% endstep %}

{% step %}
### 哪种资产暴露在公开价格之下？

EXON，上线 1.0 U 起在 NEX 现货流通——只能卖，不能买。
{% endstep %}

{% step %}
### 开单时买入了什么？

入金的 28% 按当时 1 U 等值买入 EXON，存入燃料钱包。只进不出。
{% endstep %}

{% step %}
### 提取收益时销毁的是什么？

燃料钱包里的 EXON：立即到账销毁 30%，30 天到账 20%，60 天到账 10%。
{% endstep %}
{% endstepper %}

四个问题，四个不同的答案。任何一次表述都不应该把它们中的任意两个合并。

## 叙事不是算术 <a href="#narrative-is-not-arithmetic" id="narrative-is-not-arithmetic"></a>

叫 XO「价值锚」，是为了让它不被读成一笔可有可无的记账条目——它把质押参与和长期生态命题连起来。它今天的确定功能是**质押本金代币**：本金在它上面计息，三种奖励全部以它发放。

叫 EXON「流通引擎」，解释的是为什么这种资产能随时间把数字与现实的活动连起来。它今天被确认的操作是：私募认购、上线现货（只卖不买）、1,095 天逐日释放、燃料钱包买入、提取销毁。交易、支付、兑换与手续费随五个入口逐个接入（Roadmap）。

## 一句对外的话 <a href="#one-sentence-for-external-use" id="one-sentence-for-external-use"></a>

> **NEXON 是生态，由 XO 承载价值，通过 EXON 激活流通。**

讨论当前机制时，把更窄的那句补上：**XO 是质押本金代币，本金在它上面计息、奖励以它发放；EXON 是核心价值代币，私募是唯一渠道、只能卖不能买、提取即销毁。** 两句一起说，叙事和事实源就都护住了。
