# 双币，两份工作

> EXON 是被花掉的，XO 是被押住的。

「为什么要发两个币」是关于这个网络最尖锐的问题，它值得一个结构性的答案，而不是一个营销上的答案。下面就是那个答案，也是 NEXON 在任何场合被描述时所用的那一版。

## 论证 <a href="#the-argument" id="the-argument"></a>

因为它们解决的是两个互相矛盾的问题。一个网络要让 Agent 替人动钱，需要一个越少流通越好的信任锚——谁押得多，谁的 Agent 权限就大。同时它还需要一个流通越快越好的结算单位——每天执行多少意图，就消耗多少。这两件事对同一个资产的要求正好相反：前者要沉淀，后者要周转。用一个币同时干，结果是两头都做不好——押住的人不敢花，花掉的人不愿押。所以分成两个，各自只干一件事。抵押品不是燃料。

把同一个论证按五步的顺序再说一遍。要让一个 Agent 替你动钱，网络必须先回答一个问题：凭什么信它？NEXON 的答案是抵押。你质押 XO，网络给你 Capacity——Agent 能替你执行的额度上限。押得越多，你的 Agent 能力越大，你在治理中的话语权越大，你在生态权益中的位次越高。**XO 从不参与任何一次具体的交易，它是那次交易能够发生的前提。**

而每一次执行本身要消耗燃料、要有计价单位、要在几个系统之间结清。这是 EXON 的事。

**EXON 是被花掉的，XO 是被押住的。** 抵押品不是燃料。这就是为什么是两个。

本文从这里开始使用的定义只有三句话，后面每一页都可以拿它来核对：

**XO 只押不花——它是让你的 Agent 拿到额度、让你拿到投票权与位次的抵押品。EXON 只花不押——它是每一次意图执行的燃料与结算单位。抵押品不是燃料。这就是为什么是两个。**

## 并排对照 <a href="#side-by-side" id="side-by-side"></a>

| 维度 | XO · 价值层 | EXON · 流通层 |
|---|---|---|
| 一句话 | Agent 网络的信任抵押品 | Agent 的燃料与结算单位 |
| 用户动作 | Bond（押注） | Spend（花掉） |
| 换来什么 | Capacity 执行额度 · 治理权 · 生态权益位次 | 一次被执行的意图 |
| 时间性 | 长期、沉淀，押得越久越有利 | 高频、即时、周转 |
| 价值来源 | 网络需要多少信任抵押 | 网络每天执行多少意图 |
| 心理定位 | 拿得住 | 用得上 |
| 类比 | 保证金 / 席位 | 电费 / 过路费 |
| 落地场景 | Bond · 治理投票 · 权益分层 | 早期参与轮（`Open`）· 股权挂钩结算（`Roadmap`）· 旅行兑换（`Roadmap`）· 手续费 Rebate |

最后一行的每一项都是带状态的能力，本文没有把其中任何一项描述为已上线。两种资产之间的任何兑换机制——是否存在、比例、方向——都是待定项（[OP-06](../open-parameters/README.md)），本文不以任何形式描述它。

## 那个检验 <a href="#the-test" id="the-test"></a>

接下来两页各自描述一条账本，都不借助对方来解释自己。这不是文体上的选择；这是让这个分工保持诚实的方式。「价值流转」以六条不变量为本部分收尾，其中第六条是一个你可以拿来检验本文任何一句话的方法——包括下面这些。

<details>

<summary>本文里不会出现的句子</summary>

**XO 侧。**

| 不会出现在本文中 | 因为 |
|---|---|
| 「用 XO 支付」「用 XO 买东西」「XO 抵扣手续费」 | XO 不进入任何一次支付 |
| 「XO 是生态的燃料 / gas」 | 燃料是 EXON |
| 「XO 可以用于旅行兑换 / 股权挂钩结算」 | 所有 Redemption 场景归 EXON |
| 任何把 XO 描述成「高频流通」「日常使用」的说法 | XO 是被押住的，不是被流通的 |

**EXON 侧。**

| 不会出现在本文中 | 因为 |
|---|---|
| 「押注 EXON 获得治理权」 | 治理只属于 XO |
| 「EXON 是价值储存 / 长期持有升值」 | EXON 讲周转，不讲沉淀 |
| 「持有 EXON 获得生态权益」 | 权益来自 XO 的 Bond |
| 任何把 EXON 描述成「稀缺」「通缩」「拿得住」的说法 | 这几个词描述的正是 EXON 不是什么 |

**两者。**

| 不会出现在本文中 | 因为 |
|---|---|
| 把两个资产放进同一句话做价格比较或收益比较 | 各自在各自的页上、用各自的语言描述 |
| 在代币经济定稿前描述任何兑换机制细节——包括是否可互换、比例、方向 | 待定项（OP-06） |

**一句话判别法。** 把一句话里的「XO」换成「EXON」，如果它仍然成立，那这句话一定写错了。

</details>
