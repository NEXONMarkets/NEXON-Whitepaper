# 双币，两份工作

定稿模型把质押本金资产与公开现货资产分开。

| | XO | EXON |
|---|---|---|
| 权威角色 | Staking Principal Token | Core Value Token |
| 获取 | 向 Treasury 申购，以 U 定价 | 早期轮、7228 自动建仓、现货买入 |
| 市场 | 体系内流转；协议管理价格 | TGE 起在 NEX 现货流通 |
| 经济功能 | 承载质押本金与奖励基数 | 承接程序化买入、锁仓与赎回销毁需求 |

项目方定稿中的 `U` 是与 USDT 锚定的计价单位。XO 的协议定价和体系内流转，与 EXON 的公开二级市场价格相互分离。

两者职责不得互换。XO 不再被定义为治理席位、执行额度或路由抵押；EXON 也不是“只转付给执行方而不销毁”的执行费代币。现行模型中，快速赎回会永久销毁等值 EXON。

{% hint style="info" %}
EXON 是 NEXON 项目资产，不是 NEX 平台币。NEXON 是基于 NEX 生态、由社区发起的独立项目。
{% endhint %}
