# EXON —— 流通引擎

EXON 同样有两句相互对齐、但各说各话的定义。

在 NEXON 的叙事中，EXON 是**流通引擎**，把数字金融与交易所、体验、支付、费用和消费连起来。在当前定稿机制中，EXON 是**核心价值代币**与公开现货标的，用于释放、买入、余额校验与赎回销毁。

## 名字与叙事角色 <a href="#name-and-narrative-role" id="name-and-narrative-role"></a>

`EX` 取自 exchange 与 experience。`ON` 是流通开启。EXON 是双币模型里**一直在动的那一侧**：价值可以被定价、被交换，并随着生态展开而被使用。

「流通引擎」不表示 NEXON 的每一个动作现在都要花 EXON。它不设立一个通用结算资产。未来每一项支付、费用、兑换或消费用途，都需要一个可用的产品和一份发布的条款。

## 当前的获取方式与市场角色 <a href="#current-acquisition-and-market-role" id="current-acquisition-and-market-role"></a>

EXON 可以通过三条路径获得：**早期轮认购、合格订单自动触发的 28% 建仓、二级市场买入。**

从 TGE 起，释放出来的 EXON 进入 NEX 现货账户，可以持有或交易。早期价 `0.1 U`，TGE 指导价 `1.0 U`。

## 当前的三条供需机制 <a href="#three-current-supply-and-demand-mechanisms" id="three-current-supply-and-demand-mechanisms"></a>

{% tabs %}
{% tab title="① 订单建仓" %}
每一笔合格订单把 `B = 0.28 × P` 用于按实时价买入 EXON，买到的 EXON 进入 Treasury Liquidity。

因为按实时价成交，**买到的代币数量取决于执行价格**，不由 U 金额单独决定。
{% endtab %}

{% tab title="② 燃料余额校验" %}
质押订单开立之前，用户账户里必须持有 U 价值为 `F = 0.28 × P` 的 EXON。

这笔余额**留在用户账户里**。按定稿机制，它不是费用、不是转账、不是锁仓、也不是销毁。市场价格变化时，满足同一个 U 价值所需的代币数量会变。
{% endtab %}

{% tab title="③ 赎回销毁" %}
待领收益走 T+0、30D 或 60D。这三档分别永久销毁等值的 30%、15%、0% EXON，净释放 70%、85%、100%。

如果用户手上不够带销毁档位所需的 EXON 数量，就需要先在市场上买入，才能完成赎回。
{% endtab %}
{% endtabs %}

销毁挂在**选定的赎回路径**上。它不代表一个持续的、由项目方自由裁量的市场支撑计划。

## 固定总量与尚未公布的数字 <a href="#fixed-supply-and-the-number-not-yet-published" id="fixed-supply-and-the-number-not-yet-published"></a>

定稿文件把 EXON 描述为**固定总量、按计划逐步释放**。它没有披露数字总量、完整分配、初始流通量或集中度。「固定总量」不能被扩写成一个自己编出来的数字。

早期分配在 **1,095 天、2,190 个 12 小时 Epoch** 内线性释放。后续轮次按各自条款从 T+1 开始释放。

## 长期用途（Roadmap） <a href="#long-term-utility" id="long-term-utility"></a>

EXON 更广的交易、支付、兑换、费用与消费角色属于**长期方向**。某个产品要用 EXON 之前，它的条款需要写清楚：

| 要写清楚的 | 为什么 |
|---|---|
| EXON 是必需、可选，还是在结算前被兑换 | 决定用户是否真的需要持有它 |
| 价格来源、报价有效期、流动性来源与滑点处理 | 决定用户实际付出多少 |
| 任何费用的收取方与用途 | 决定钱去了哪里 |
| 托管与退款处理 | 决定出问题时资产在谁手上 |
| 支持的辖区与用户资格 | 决定谁能用 |
| 商户、发卡机构或其他责任执行方 | 决定找谁 |
| 这次使用是改变供应量，还是只转移所有权 | 决定它对代币经济的真实影响 |

AI 原生 PayFi、商城、稳定币卡与社交价值互动，都适用这张表。**本文不假设存在一份统一的费率表或统一的支付路径。**

## EXON 的三句话 <a href="#exon-in-three-sentences" id="exon-in-three-sentences"></a>

1. **叙事**：EXON 是 NEXON 的流通引擎。
2. **当前机制**：EXON 是核心价值代币与现货 / 释放 / 买入 / 校验 / 销毁资产。
3. **长期方向**：具体的交易、支付、兑换、费用与消费用途，需要产品支持与已发布的规则。
