# EXON —— 核心价值代币

EXON 是定稿模型中唯一核心价值代币与现货资产，可通过早期轮、28% 自动建仓或二级市场获得。TGE 起，释放进入 NEX 现货账户，可自由持有或交易。

三套机制形成需求或约束可用供给：

1. 每笔完整订单把 28% 按实时价买入 EXON，并把所得注入 Treasury Liquidity。
2. 开单前需通过等于订单额 28% 的 EXON 燃料余额检查；资产仍留在用户账户。
3. 收益赎回按所选速度永久销毁 30%、15% 或 0% 的等值 EXON；余额不足时须先从现货买入。

EXON 采用固定总量、逐步释放机制。定稿未给出数字总量、完整分配或初始流通量，本白皮书不作估算。

TGE 的 `1.0 U` 是指导价，不是保证成交价；早期 `0.1 U` 与未来市场价格也不构成倍数承诺。

{% hint style="danger" %}
EXON 可能大幅波动或缺乏流动性。程序化买入与销毁不保证价格上涨、退出价格或本金可收回。
{% endhint %}
