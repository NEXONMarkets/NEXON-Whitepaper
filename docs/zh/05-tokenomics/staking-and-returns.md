# 质押与收益

计息基数是 72% 质押本金 `S`。定稿 Base APY 为 200%，每 12 小时结算，并乘以所选期限权重 `w`。

```text
r_epoch = (S × APY × w) / (365 × 2)
r_day   = (S × APY × w) / 365
R_term  = S × APY × w × T / 365
```

| 期限 `T` | 权重 `w` | 流动性条件 |
|---:|---:|---|
| 30 天 | 1.00 | 灵活档；提前退出扣除本金 10%–15% |
| 90 天 | 1.10 | 到期解锁 |
| 180 天 | 1.20 | 到期解锁 |
| 360 天 | 1.35 | 到期解锁 |
| 540 天 | 1.50 | 项目方定稿推荐长期档 |

续期阶梯为 `30 → 90 → 180 → 360 → 540 天`，逐级续期累计锁定约 1,200–1,400 天。用户也可到期赎回后另开 540 天订单。

30 天灵活档提前退出：

```text
Refund = S × (1 − λ)，其中 λ 为 10%–15%
```

动态奖励依据社区贡献和团队业绩定级，相邻等级采用等级极差（Differential）Matching Bonus，与静态收益同一个 Epoch 结算。Reward Payout Ratio 为 150%–200%，可按轮次和市场状态调节。等级名称、门槛及极差比例尚未公布，因此无法从本白皮书计算个人动态奖励。

{% hint style="danger" %}
200% Base APY 与 150%–200% 拨备率均为可调协议参数，不是可实现收益保证，也未计入币价、流动性、滑点、费用、税务、托管、规则变化或本金损失。
{% endhint %}
