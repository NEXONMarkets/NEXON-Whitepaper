# 分配与释放

> NEXON 是生态，XO 承载价值，EXON 驱动流通。

{% hint style="warning" %}
**第 1 版没有数字。** 本页说明将要披露什么、依据哪些原则。它不含任何总量、分配、解锁、释放或兑换数字。将来会填上数字的每一个格子都在下面作为待定项列出，而第 2 版填这些格子时不会重写本页。
{% endhint %}

## 数字为什么要等 <a href="#why-the-figures-wait" id="why-the-figures-wait"></a>

代币经济由项目方设计，目前仍在定稿中。在它定稿之前，本文不会描述两种资产之间的兑换机制、比例或方向，也不会描述任何总量。过早给出的数字，后面一旦调整，伤的是社区的信任。相比之下，机制已经确定到可以写下来的程度——这也是本部分其余各页能完整描述角色、流向与不变量，而本页只描述一张空表的原因。

## 数字将遵循的四条原则 <a href="#four-principles-the-figures-will-follow" id="four-principles-the-figures-will-follow"></a>

1. **XO 的分配是为了留下来。** 分配与解锁是为那些押注并且持续押着的参与者设计的。没有任何一个类别是为了尽快脱手而设计的，也没有任何一个类别豁免于 [XO 页面](xo.md)所描述的押注机制。
2. **EXON 的发行锚定执行。** 进入流通的数量跟随被执行的 Intent，而不只跟随一份日历。一条执行得少的结算轨，需要的也少。
3. **早期参与的分配默认锁定并线性释放。** 任何早期参与轮的条款都是待定项（[OP-23](../open-parameters/README.md)）；但它释放的默认形状不是待定项——先锁定，后线性。
4. **披露要么完整，要么不发生。** 完整的分配表与释放曲线在同一个版本里一起发布，每个类别都被命名，每条计划都被画出。不发布局部数字。
