# 治理

不得从持币事实推导治理权。定稿经济模型把 XO 定义为质押本金代币，把 EXON 定义为核心价值与现货代币；没有授予任何一方投票权，也没有公布链上投票设计。

当前阶段由 NEXON 团队管理可调参数，包括质押设置、奖励拨备范围及逐轮条款。每次生产变更应包含：

1. 生效时间与参数版本；
2. 变更字段和受影响订单；
3. 通过项目官方渠道发布的公告；
4. 防止追溯改写已结算 Epoch 的可审计记录。

团队不得把未公布字段写成已确定。EXON 数字总量、完整分配、初始流通、未来轮次限额及完整等级极差表仍是开放项。

NEXON 是基于 NEX 生态、由社区发起的独立项目。NEX 的交易所身份、牌照或人员不批准或保证 Staking Platform 的结果。
