# 法律声明

本白皮书用于说明一个正在建设中的项目。它不是要约、要约邀请、投资建议、法律意见或税务意见，也不是在任何辖区内关于可用性的承诺。除非被并入另行具有约束力的产品条款，本文不构成合同。

## 关于两种资产 <a href="#on-the-two-assets" id="on-the-two-assets"></a>

XO 在叙事上被描述为价值锚，在机制上是质押本金代币。EXON 在叙事上被描述为流通引擎，在机制上是 NEXON 的核心价值代币与现货标的。**这两组描述不是任何辖区下的最终法律定性。** 两者均不代表股权、债权、存款，也不代表对 NEX 的索取权或有保证的收入权利。

## 关于数字 <a href="#on-the-numbers" id="on-the-numbers"></a>

所有年化、奖励、价格、ROI 与静态回本数字，都是**协议参数或来自项目文件的条件化演算**。它们省略或简化了重要因素，包括价格波动、流动性、滑点、费用、税费、托管、对手方履约、技术故障、规则变更与法律限制。实际结果可能与之显著不同。

## 关于项目关系 <a href="#on-the-project-relationship" id="on-the-project-relationship"></a>

NEXON 是基于 NEX 生态、由社区发起的独立项目。**NEX 的资质或牌照不保护本金，也不担保 Staking Platform 的表现。**

## 关于长期产品 <a href="#on-the-long-term-products" id="on-the-long-term-products"></a>

AI 原生 PayFi、钱包、第三方预测市场入口、商城、稳定币卡与去中心化社交 App 属于规划方向。对它们的描述不承诺上线、功能、服务可用性、运营方覆盖或监管资格。

AI 的输出可能出错，它替代不了用户审批，也替代不了专业建议。商户、发卡机构、托管人、场所与第三方协议均按其自身条款与风险运作。

## 关于不可逆与追偿 <a href="#on-irreversibility-and-recovery" id="on-irreversibility-and-recovery"></a>

数字资产转账与市价单可能不可逆。卡片或商城的追偿取决于负责的发卡机构、支付服务商或供应商。**程序化买入与销毁不保证价格支撑。** 一个统一的界面不会让 NEXON 成为它所显示的每一笔余额或每一条路径的托管人或担保人。

## 关于参与 <a href="#on-participation" id="on-participation"></a>

参与可能受限或不可用。考虑参与的人应当评估适用条款，并获取独立的专业建议。**参与者可能损失部分或全部本金。**
