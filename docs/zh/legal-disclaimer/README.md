# 法律声明

{% hint style="danger" %}
**在依赖本文任何内容之前，先读这一段。** 本文描述的是一个拟议中的协议设计。它不是投资建议，不是要约或招揽，也不承诺其中任何能力一定会被建成或向你开放。第一版刻意不含任何代币参数。
{% endhint %}

本文描述一个价值连接网络：Agent 在资本市场、数字资产与真实消费之间做翻译。它解释一套设计，不出售任何东西。

## 非投资建议 <a href="#not-investment-advice" id="not-investment-advice"></a>

本文没有任何内容构成财务、法律、税务或投资建议，也没有任何内容是针对你的个人情况写的。它说的是一个协议打算怎么运转，而不是参与其中是否适合你。据此采取任何行动之前，请自行寻求专业意见。

## 非要约，非招揽 <a href="#not-an-offer-or-solicitation" id="not-an-offer-or-solicitation"></a>

本文在任何辖区都不是招股说明书、发行文件或任何形式的招揽。它不出售任何东西，也不邀请任何人购买任何资产、权利或参与资格。任何早期参与轮（`Open`，[OP-23](../open-parameters/README.md)）都将按其自身条款进行，不受本文约束。本文不承诺任何交易所上线，也不应由此作出任何推断。

## 前瞻性陈述与状态徽章 <a href="#forward-looking-statements-and-status-badges" id="forward-looking-statements-and-status-badges"></a>

尚不存在的能力，在本文中作为设计意图来描述，而不是作为关于某个产品的事实。三个徽章固定了这类陈述的读法：

- `Roadmap`——已描述，未建成。不构成按所述方式建成它的承诺，也不构成建成它的承诺。
- `Design Target`——当前设计假定的取值；第二版之前可能变更，恕不另行通知。
- `Open`——尚未选定取值；具体数字、名称或参与方列于[待定参数汇总](../open-parameters/README.md)。

`In development` 不承诺任何完成日期。第一版没有把任何能力描述为已上线。

## 辖区 <a href="#jurisdictions" id="jurisdictions"></a>

NEXON 的能力将在哪里、向谁提供，是一个待定参数（`Open`，[OP-21](../open-parameters/README.md)）。在它确定之前，请默认本文所述内容在你所在地可能部分或全部不可用、受限或被禁止。

## XO 与 EXON 的性质 <a href="#nature-of-xo-and-exon" id="nature-of-xo-and-exon"></a>

XO 与 EXON 都是功能型代币：XO 用于获取 Agent 执行额度与治理权，EXON 用于结算与消费流通。两者都不代表任何主体的股权、债权或收益分配权。项目会按上所与合规要求出具正式的法律意见文件。

以上定性是项目自己的表述，不是法律意见；每一项敏感能力由谁执行，见[合规立场](../08-compliance/README.md)。

## 与 NEX 的关系 <a href="#relationship-to-nex" id="relationship-to-nex"></a>

NEXON 是在 NEX 生态内由社区自发发起的独立项目，不是 NEX 的官方产品；XO 与 EXON 都不是交易所平台币。关于 NEX、其牌照或其产品的任何陈述，都应由 NEX 自己作出；本文不代其作任何陈述。

## 版本与语言 <a href="#versions-and-canonical-language" id="versions-and-canonical-language"></a>

本文为第一版，即机制版。总量、分配、解锁、释放以及两种资产之间的任何关系都是待定参数，将在第二版填入，且不重写引用它们的章节；第二版也可能对第一版的任何内容作出更正、重述或撤回。本文以英文版为准。本中文版为本地化改写，如有出入以英文版为准——但[术语表](../glossary/README.md)标明先以中文写成的那几句除外。
