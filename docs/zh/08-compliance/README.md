# 合规立场

> XO 与 EXON 都是功能型代币：XO 用于获取 Agent 执行额度与治理权，EXON 用于结算与消费流通。两者都不代表任何主体的股权、债权或收益分配权。项目会按上所与合规要求出具正式的法律意见文件。

一个 Translation Layer（翻译层），从结构上就注定会触及受监管的活动。一条 Route（路径）横跨资本市场、数字资产与真实消费，几乎任何一条 Route 都至少有一段腿，是由持有相应牌照的一方来执行的。立场由此而来：NEXON 负责选路，持牌方负责执行。这一节讲清三件事：两种资产是什么；协议在辖区与身份问题上站在哪里；以及逐项说明——凡是法律定性取决于「谁来做」的活动，各由谁来做。

## 定性 <a href="#characterization" id="characterization"></a>

上面那句话，就是全部。XO 被押住，用来换取 Capacity（执行额度）与资格；EXON 被花掉，用来结算 Route。两者都不是股份、不是票据、也不是对任何主体收入的索取权。押住 XO 让你的 Agent 拿到行动资格，而资格不是分红。消耗 EXON 是在为执行付费，手续费上的 Rebate（抵扣）是折扣，不是分配。

关于两种资产的正式法律意见，会随后续流程的要求出具。本文不是那份意见；在它存在之前，任何代表 NEXON 发声的人都不会就法律定性给出个人判断。

## 与 NEX 的关系 <a href="#relationship-to-nex" id="relationship-to-nex"></a>

NEXON 是在 NEX 生态内由社区自发发起的独立项目，不是 NEX 的官方产品；XO 与 EXON 都不是交易所平台币。NEX 是一家持牌的数字资产交易所；NEXON 依托它的资源与影响力，上线初期，XO 通过一款由 NEX 按自有条款运营的托管型产品完成押注（[信任与抵押](../03-architecture/trust-and-bonding.md)）。NEX 的牌照、披露与产品条款属于 NEX 自己，由 NEX 自行发布。本文不转述它们，本文中的任何内容也都不是 NEX 的陈述，不代表 NEX。

## 辖区与身份 <a href="#jurisdiction-and-identity" id="jurisdiction-and-identity"></a>

辖区立场——协议在哪些地方提供、在哪些地方不提供——是 `Open`（OP-21）。在它定下来之前，这里不把任何辖区写成已覆盖或已排除；定下来之后，名单放在[法律声明](../legal-disclaimer/README.md)里。

身份沿用网络上其他所有受监管活动的同一套模式：持牌方来做，协议只记录「做过了」。客户身份识别（KYC）与反洗钱（AML）核验由持牌的身份服务商执行，并出具一份证明（attestation）；协议只保存对这份证明的引用，从不保存底层文件。需要身份的腿——经持牌场所的资本市场腿（`Roadmap`）、经持牌发卡机构的卡额度（`Roadmap`）——以证明存在且仍在有效期内为放行条件。服务商及其覆盖的辖区是 `Open`（OP-22）。

## 依赖持牌方的能力 <a href="#capabilities-that-depend-on-a-licensed-party" id="capabilities-that-depend-on-a-licensed-party"></a>

本文中有七项能力，视辖区与执行方的不同，属于或可能属于受监管活动。每一项都以同一种形式披露，遵循同一条规则：协议提供 Intent（意图）、Route 与接入；受监管的动作，由持有相应牌照的一方来完成。

| 能力 | 谁执行 | NEXON 的角色 | 状态 |
|---|---|---|---|
| **上线初期的托管型 XO 押注** | NEX，按其自有产品条款 | 在 Bond Check（额度校验）时读取记录；不设定任何回报，也不承诺任何回报 | `In development`（OP-31） |
| **早期参与轮** | 发行主体，条款定稿后披露 | 公布条款；份额默认锁定并线性释放（[分配与释放](../05-tokenomics/distribution.md)） | `Open`（OP-23） |
| **股权挂钩结算** | 持牌第三方执行，NEXON 不经纪证券，也从不持有仓位 | 把一个 Intent 的资本市场腿路由给该第三方，并记录其确认 | `Roadmap`（OP-24） |
| **旅行兑换** | 以 Leg Executor（腿执行方）身份接入商城的旅行供应商 | 落地 Real Leg（现实腿）并出具 Landing Receipt（落地凭证）；不持有任何库存 | `Roadmap` |
| **稳定币卡** | 持牌发卡机构与合规聚合通道 | 仅为接入层：Land（落地）步骤交付一笔卡额度；协议不发卡，也不持有任何卡内资金 | `Roadmap`（OP-25） |
| **Foresight（前瞻）** | 产生信号的那些场所的独立运营方 | 仅提供结算与入口基建；协议不运营任何场所，也不做市 | `Roadmap`（OP-26） |
| **Patience（耐心）** | 钱包把闲置资产路由进去的链上收益来源（浮动 · 非承诺 · 非保本） | 仅在等待窗口内做路由；协议不设定、也不承诺任何收益率 | `Roadmap`（OP-27） |

有两行不论在本文哪里出现，都用固定写法。Patience 每一次提及都写作**链上收益（浮动 · 非承诺 · 非保本）**，因为任何更短的写法读起来都像存款。股权挂钩结算永远写作**股权挂钩结算（持牌第三方执行，NEXON 不经纪证券）**，因为任何更短的写法读起来都像经纪业务。
