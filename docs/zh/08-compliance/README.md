# 合规立场

NEXON 是基于 NEX 生态、由社区发起的独立项目，不是 NEX 官方产品。XO 与 EXON 是 NEXON 项目资产，不是 NEX 平台币。

运营边界明确：NEX Main Exchange/CEX 是承载 EXON 现货、IEO 与释放呈现的合规现货层；Staking Platform 独立运行单币质押、期限权重、动态奖励与赎回。不得借交易所牌照或披露暗示监管机构认可某个质押回报。

经济传播必须区分四类陈述：

| 类型 | 必须采取的处理 |
|---|---|
| 已定参数 | 写明数值、生效版本及可调属性 |
| 条件化案例 | 在结果旁列出全部价格与执行假设 |
| 市场结果 | 不保证价格、流动性、收益或回本 |
| 未公布字段 | 标记开放，不估算、不补齐 |

KYC、AML、托管、交易执行及任何受监管的现实活动，必须由相应责任方依据适用资质与条款执行。可用性取决于辖区和参与资格。
