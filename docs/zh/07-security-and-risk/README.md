# 安全与风险

现行模型使参与者面对多类相互独立的风险：

- **本金风险。** 30 天档提前退出扣除质押基数的 10%–15%，且还可能发生其他损失。
- **市场与流动性风险。** EXON 可能下跌、缺乏买方或产生显著滑点。
- **参数风险。** 在模型允许调节的范围内，Base APY、权重、拨备率与未来轮次条款可能改变。
- **释放压力。** 固定总量不阻止已释放 EXON 进入现货后形成卖压。
- **托管与对手方风险。** 交易所、Treasury、合约或服务方可能故障或不可用。
- **技术风险。** 漏洞、错误价格输入、记账错误或凭证泄露都可能造成损失。
- **法律风险。** 可用性和代币定性因辖区而异。
- **披露风险。** 条件化 ROI 或回本数学可能被误读成预期结果。

控制措施应包括参数版本管理、职责分离审批、余额对账、代码审查、合约审计、监控、事件响应及公开变更通知。它们降低风险，但不能消除风险。

{% hint style="danger" %}
EXON 程序化买入、锁仓和销毁不会形成价格底线，也不保护本金。参与者可能损失部分或全部本金。
{% endhint %}
