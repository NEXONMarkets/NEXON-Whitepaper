# 待定参数汇总

2026 年 9 月 6 日经济模型已经确定代币角色、7228、燃料储备、早期档位、释放周期、Base APY、期限权重、赎回销毁与动态拨备范围。以下字段仍然开放：

| 编号 | 字段 | 影响 |
|---|---|---|
| OP-T01 | EXON 数字总量 | 供给与稀释分析 |
| OP-T02 | 完整分配与初始流通 | 持有与释放集中度 |
| OP-T03 | 后续轮规模、折扣与个人上限 | 逐轮参与条款 |
| OP-T04 | 动态奖励等级、门槛与极差比例 | 个人 Matching Bonus 计算 |
| OP-T05 | 最终 TGE 与后续轮日期 | 可用性与释放起点 |
| OP-L01 | 可参与辖区和主体类型 | 法律可用性 |
| OP-L02 | 责任法律主体与服务方条款 | 责任与披露 |
| OP-S01 | 合约地址、审计与控制设计 | 技术核验 |

开放字段必须保持显式开放。后续书面决定应注明生效范围，并同步更新经济章节、中英双语树与机器可读权威登记表。
