# 待定参数汇总

2026 年 9 月 6 日的经济文件关掉了机制层面的主要问题：当前代币角色、7228 拆分、燃料储备、早期档位、释放排程、基础年化、期限权重、赎回销毁与动态支付区间。9 月 8 日的叙事补充关掉了品牌含义、双币叙事与五产品方向。

**这两份来源都没有填上下面这些实现字段。** 它们保持可见的待定状态。

## 关闭规则 <a href="#the-closure-rule" id="the-closure-rule"></a>

一个待定字段必须**保持可见的待定状态**。后续的书面决定要写明：批准方、依据、生效范围、版本、影响的产品。然后**同时**更新事实登记表、中英两棵文档树、Wiki、用户披露与校验测试。

三条不能用来关闭字段的做法：

* **叙事定位关不掉一个经济字段。**
* **一张产品原型图关不掉一个托管或法律字段。**
* **第三方公告关不掉一个 NEXON 的运营字段**，除非这层责任关系有文件支撑。

冲突的旧材料留作历史档案，不能用来填空。

**待定不等于不重要，也不等于默认成立。** 它意味着项目刻意保留了一条决策边界，好让读者能分清哪些是已确认的机制、哪些是未来的设计。
