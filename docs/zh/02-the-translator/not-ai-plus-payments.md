# 这不是「AI + 支付」

限额、白名单、撤销和限定权限回答的是安全问题：Agent 可以做什么？翻译回答的是能力问题：用户要求的一个结果，如何在以不同语言描述价值的系统之间完成？

NEXON 把这些问题分开。Agent 层理解 Intent 并提出受控执行；经济层独立定义 7228、XO 质押本金、EXON 现货价值、期限加权收益与赎回销毁。任何代币余额都不能替代用户审批或持牌执行。

这一分离对披露至关重要。产品自动化不会让质押参数更安全；高 APY 不能证明产品采用；现货上线也不能证明 Agent 输出正确。每类陈述都须由自己的证据支撑。
