# 译者

NEXON 把用户目标视为 Intent，而不是要求用户手动操作每个产品。Agent 在可用市场与服务之间提出路径，用户保留审批权，持牌场所或供应商执行相应受监管或现实环节。

五个控制步骤：

1. **Parse** 目标和约束。
2. **Route** 可用场所、流动性与供应商。
3. **Policy Check** 账户资格、订单限额、余额及所需 EXON 燃料储备。
4. **Execute** 仅在限定权限内执行已批准分段。
5. **Land the Real Leg**，记录完成或回滚。

Staking Platform 不是 Agent 执行的资格前提；其 XO 本金、EXON 储备与奖励规则是独立经济产品，见[通证经济](../05-tokenomics/README.md)。
