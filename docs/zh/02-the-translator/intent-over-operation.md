# 表达意图，而非操作产品

Intent 记录期望结果、金额、截止时间、可接受滑点、可用场所与审批模式。执行前，运行时展示包含每个分段、报价、责任执行方与有效期的完整路径。

## 五个步骤 <a href="#five-steps" id="five-steps"></a>

1. **Parse。** 把自然语言转为结构化请求；缺少重要信息时先追问。
2. **Route。** 生成完整提案，此时不移动资产。
3. **Policy Check。** 校验身份、辖区、余额、用户限额和具体产品条件；质押订单还要校验 28% EXON 储备。
4. **Execute。** 每次只为一段已批准操作授予有边界、有时限的权限。
5. **Land。** 记录最终结果；某段失败时停止，并进入已披露的回滚或争议流程。

路径只能使用向用户展示的资产和权限。XO 不授予 Agent 执行资格；在定稿经济模型下，EXON 也不是所有路径通用的手续费。
