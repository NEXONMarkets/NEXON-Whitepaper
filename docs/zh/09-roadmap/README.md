# 路线图

路线图使用可核验交付门槛，而不是暗示收益的里程碑。

| 门槛 | 可核验完成证据 |
|---|---|
| 经济事实源 | 版本化规则可复现定稿 7228、释放、质押与赎回计算 |
| 双层隔离 | NEX 现货与 Staking Platform 的权限、账本及披露可独立测试 |
| 订单记账 | 每单记录本金、建仓、质押基数、期限、权重与参数版本 |
| 收益赎回 | T+0、30D、60D 均可对账净释放与等值 EXON 销毁 |
| 风险控制 | 审查、审计、监控、事件处置与公开变更通知可运行 |
| 开放字段 | 总量、分配、动态等级及轮次条款只在正式批准后发布 |

日期、合约地址、服务可用性与辖区覆盖应在确认后通过官方渠道公告。指导价、APY 或演算案例不是路线图目标。
