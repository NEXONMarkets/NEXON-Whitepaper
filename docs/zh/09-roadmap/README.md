## 阶段一　经济与账户基础 <a href="#phase-1-economic-and-account-foundation" id="phase-1-economic-and-account-foundation"></a>

**目标：** 把定稿的经济机制实现出来并验证它。

完成的证据是一套带版本的规则，能够复现：28% 燃料买入与其余兑换 XO 的订单拆分、1,095 天释放、每 12 小时 0.3% – 1.0% 的结算、期限加成、第 31 天退出窗口、三档到账与燃料钱包销毁、20 代推广奖励与 V1 – V12 领导奖金。

NEX Main Exchange / CEX 与 Staking Platform 拥有**可分离的权限、账本与披露**。每一笔订单都记录本金、建仓、质押基数、期限、权重与参数版本。

## 阶段二　AI 原生 PayFi <a href="#phase-2-ai-native-payfi" id="phase-2-ai-native-payfi"></a>

**目标：** 立起叙事的第二重点——一条从金融意图到执行证据的受控路径。

门槛包括：已发布的意图 schema、路径预览、确定性策略校验、范围化审批、撤销、执行方白名单、报价有效期、防重复执行、凭证、失败处理、模型风险控制、隐私条款与安全审查。**支持的动作、资产、费用、辖区与责任执行方，要在可用之前一一指名。**

AI 在这一阶段负责翻译与编排。它不改经济机制，不产生收益，也不成为托管人或受监管的执行方。

## 阶段三　钱包、商城与稳定币卡 <a href="#phase-3-wallet-marketplace-and-stablecoin-card" id="phase-3-wallet-marketplace-and-stablecoin-card"></a>

**目标：** 把决策状态接到现实使用上。

| 产品 | 门槛 |
|---|---|
| 钱包 | 托管架构、权限管理、恢复流程、质押展示、清晰分离的第三方预测市场入口 |
| 商城 | 供应商准入、库存、支付与退款条款、履约凭证、隐私与争议流程 |
| 稳定币卡 | 责任持牌发卡 / 运营方、辖区覆盖、接受的充值资产、费用、资金保管、反欺诈与持卡人支持 |

任何 EXON 的支付、费用或消费用途，以及任何基于 XO 的产品权益，都需要**明确的产品条款**。这里不暗示任何通用用途。

## 阶段四　去中心化金融社交网络 <a href="#phase-4-decentralized-financial-social-network" id="phase-4-decentralized-financial-social-network"></a>

**目标：** 把用户控制的价值闭环走完——发现、决策、成路、使用，以及语境回流。

门槛包括：可携带身份、社区与治理规则、策略内容披露、金融意图的隐私保护连接、用户自主的分享控制、生态治理规格，以及产品之间安全的互操作。**社交信息始终是上游语境，不能无声地授权执行。**

## 跨阶段门槛 <a href="#cross-phase-gates" id="cross-phase-gates"></a>

每个阶段还共同要求：可问责的实体、适用的法律审查、事件处理、独立的安全证据、监控、变更公告，以及与叙事和经济事实源保持一致的双语文档。

以下项目在正式批准之前保持[待定](../open-parameters/README.md)：合约地址、上线后 1:1 配置的切换节点、领导奖金各级执行值、产品运营方、支持的辖区、费用与服务水平。
